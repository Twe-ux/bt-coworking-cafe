# Documentation BT Coworking Café

Ce dossier contient toute la documentation technique et les prototypes du projet.

## Structure

### Documentation technique

- **CRON_SETUP.md** - Configuration du cron job pour la publication automatique des articles
- **DEBUG_CONTACT_MAILS.md** - Guide de débogage pour le système de contact
- **MESSAGERIE.md** - Documentation du système de messagerie
- **STRIPE_SETUP.md** - Configuration de Stripe pour les paiements
- **task.md** - Liste des tâches du système blog
- **TASKS.md** - État d'avancement du système de réservation

### Prototypes

Le dossier `prototypes/` contient les prototypes HTML créés pendant le développement :

- **calendar-design-*.html** - Maquettes du calendrier de réservation
- **layout-option-*.html** - Maquettes de la topbar et du layout du dashboard

Ces prototypes ont servi de référence visuelle lors de l'implémentation.

## Fichiers à la racine du projet

- **README.md** - Documentation principale du projet
- **CLAUDE.md** - Instructions pour Claude Code (configuration IDE)
